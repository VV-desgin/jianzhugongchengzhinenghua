# 21 量化对比实验方案（人工 vs 自动，支撑「时间缩短≥50%」）

> 依据：赛题方案子赛题4 关键指标「BOM/工艺/纤芯自动生成且时间缩短≥50%」；docs/08 优化对比评测记录。
> 状态：方案 v1（2026-08-22）。数据采集需团队人工配合；采集完成后结果并入 EVALUATION_REPORT。

## 一、目标与指标

| 指标 | 公式 | 目标 |
|---|---|---|
| 时间缩短率 | (人工耗时 − 自动耗时) / 人工耗时 × 100% | ≥ 50% |
| 检出一致率 | 自动与人工共同检出的问题数 / 二者并集问题数 | ≥ 90%（支撑准确率 ≥95% 的交叉证据） |
| 检出覆盖 | 自动检出的规则数 / 应检规则数 | 100%（按工程类别路由） |

## 二、样本集（建议 N=11，复用评测表 2.1）

TC-01（正确工程 2.6）、TC-02/TC-03/TC-04/TC-05/TC-06/TC-07/TC-08/TC-09（仅占用/仅重复 2 包）、TC-10（BOM 2.0）；必要时补赛题一/赛题四（真实大包，仅记录不做人工全量）。

## 三、实验协议

1. **人工组**：由 2 名熟悉规则的团队成员独立审查每包（同一人不得先看自动结果），记录：
   - 耗时（从打开工程包到输出问题清单）；
   - 检出问题（规则编号/对象 ID/简述）。
2. **自动组**：`POST /agent/data-pipeline`（或 Dify 总控全流程），记录：
   - 端到端耗时（Dify run 输出 duration 或本地接口耗时）；
   - review.total/passed/failed/warning 与 issues 明细。
3. **对照**：逐包比对（按规则编号+对象 ID 对齐），计算一致率；不一致项人工仲裁（以官方条款 docs/13 为准）。
4. **归档**：原始记录入 `05_测试记录/量化对比/`（本方案附模板 docs/25）；结果汇总表回填后并入 EVALUATION_REPORT。

## 四、输出物

- 记录模板 xlsx（docs/25_量化对比记录模板.xlsx，含示例行）；
- 对比报告（完成后新增 docs/26_量化对比报告.md）：每包耗时对比表 + 一致率 + 仲裁结论。

## 五、时间与分工

- 人工组：每人 11 包 × 约 20~40 分钟/包（取决于包复杂度）≈ 4~7 小时/人；
- 自动组：脚本化执行约 1~2 小时（本机或云服务器）；
- 仲裁：0.5~1 天。
- 建议 9-05 前完成采集，9-10 前完成报告。

## 六、风险

- 人工标准不统一 → 用 docs/19 标准答案表作为对照基准；
- 大包（赛题一/四）人工审查成本高 → 仅纳入时间对比、不做全量人工检出；
- 自动耗时受服务器负载影响 → 同一包连续跑 3 次取中位数。
