## 三、参数设定建议（官方已授权"自行设定"，以下为行业惯例+标准依据方向）

### D01 损耗率（business_params.json → loss_rates）

| 物料类别 | 建议损耗率 | 依据方向 |
|---|---|---|
| 光缆（500002050） | 5%（含敷设/接续损耗分摊） | YD/T 5102 施工工艺（敷设张力、弯曲半径、接续损耗）；行业定额惯例 3~5% |
| 钢绞线（200001033） | 3% | 弧垂、张力、剪口余量；架空杆路施工惯例 |
| 电杆/箱体（结构件） | 0%（备品 1~2% 可选） | 整数采购无本体损耗；GB 51158 材料要求 |
| 易损件（挂钩/线夹/夹具等） | 2~3% | 施工损耗/丢失惯例 |

### D02 预留长度（reserve_lengths）

| 场景 | 建议取值 | 依据方向 |
|---|---|---|
| PCP 接头盒内光纤余长 | 1.35m/接头盒 | YD/T 5102 接头盒内光纤盘留要求（1.2~1.5m 惯例） |
| 光缆接头每侧盘留 | 7.5m/接头 | 架空/管道接头余留惯例（5~10m） |
| 人孔/手孔盘留 | 0.75m/处 | 人孔弯曲余留惯例（0.5~1m） |
| 电杆上下杆预留 | 7.5m/杆 | 架空杆路杆上余留惯例（5~10m） |
| 端点预留 | 3.5m/处 | 光箱/入口端余留惯例（2~5m） |

### D03 包装规格（packaging）

| 物料 | 建议规格 | 依据方向 |
|---|---|---|
| 光缆 | 2km/盘（长段落可 4km/盘） | 光缆标准盘长（YD/T 光缆产品系列常用规格） |
| 钢绞线 | 500m/卷（可 1000m/卷） | 市场常用卷长规格 |
| 熔接/标签/测试 | 按件/点，不取整 | 计数类物料 |

## 四、落地建议

1. 将上述默认值写入 `business_params.json`（当前默认值已与此一致），`_meta.source` 改为"依据行业标准惯例设定（YD/T 5102-2024、GB 51158-2015 等），组委会已授权自行设定"。
2. 标准全文条款级核对（如具体预留数值、安全距离）建议登录 std.samr.gov.cn/hb 或通过工信部标准服务平台获取 YD/T 5102-2024 全文后逐条核对；当前数值为行业惯例，符合"标准可自行设定"授权。
3. 待补充：验收规范/杆路规范编号确认（见第二节"待补充确认"）。
