# Dify 网页端修改操作手册（2026-09-05）

> 适用：你在 Dify 网页端手动修改，不改 YAML/仓库文件。
> 入口：Dify 控制台 → 应用列表 → 对应应用 →「编排 / Studio」。
> 通用规则：Code 节点右侧面板分「输入变量 / 输出变量 / 代码」；End 节点右侧是「输出变量」列表；每次改完必须点「保存」并「发布」，API 调用的是已发布版本。

切到「代码」页，找到最外层 return（返回 status/construction_status/…/work_packages 的位置），在 return 字典中增加：


（`environment_pending_count`、`manual_package_count`、`pending_review_items` 在代码中已经存在，直接补到 return。）

### 1.3 节点「代码执行」——material_for_codes 修改

在代码中定位 `def material_for_codes(codes):`，把匹配与取数部分改成：

```python
item_ids = item.get("source_object_ids") or []
hit = bool(set(item_ids) & set(source_ids)) if source_ids else bool(set(codes) & set(item_ids))
if not hit:
    continue
qty = item.get("quantity")
if qty is None:
    qty = item.get("最终数量")
unit = item.get("unit") or item.get("单位")
material_code = item.get("material_code") or item.get("物料编码")
material_name = item.get("material_name") or item.get("物料名称")
```

调用处同步传对象 ID：`material_for_codes(codes, source_ids)`。

### 1.4 节点「代码执行」——fiber_pending 修改

找到：
```python
fiber_pending = bool(fiber_conflicts or fiber_status == "待确认")
```
改成：
```python
fiber_pending = bool(
    fiber_conflicts
    or fiber_status in ("待确认", "失败", "FAILED", "解析失败")
)
```

### 1.5 End 节点「输出」——新增 3 个输出

| manual_package_count | number | 代码执行 → manual_package_count |
| pending_review_items_json | string | 代码执行 → pending_review_items_json |

保存并发布该应用。

### 2.1 节点「解析黄福林BOM结果」（1786023921854）

点击该 Code 节点：
1. 右侧「输入变量」→ 添加两个变量：

|---|---|---|
| api_success | boolean | 解析BOM_DEV_API返回 → api_success |
| api_error | string | 解析BOM_DEV_API返回 → api_error |

2. 「代码」页，把函数开头改为：

```python
def main(bom_result_json: str = "", api_success=None, api_error: str = "") -> dict:
    if api_success is False:
        return {"bom_success": False, "bom_error": str(api_error or "BOM API 失败"),
                "final_bom": [], "standard_bom_table": [], "need_confirm_list": [],
                "bom_count": 0, "confirm_count": 0}
    try:
        if isinstance(bom_result_json, str):
            text = bom_result_json.strip()
            if not text:
                raise ValueError("BOM结果为空")
            data = json.loads(text)
```

3. 保存。

### 2.2 节点「解析真实接口返回」（1785836509606）

1. 右侧「输出变量」新增：

| 变量名 | 类型 |
|---|---|
| review_state | string |
| review_reason | string |
| review_error | string |

2. 「代码」页修改 review 读取段：

把：
```python
review = data.get("review") if isinstance(data.get("review"), dict) else {}
issues = review.get("issues") if isinstance(review.get("issues"), list) else []
```
改成：
```python
review = data.get("review") if isinstance(data.get("review"), dict) else None
review_state = "executed"
review_reason = ""
review_error = ""
if review is None:
    review_state = "missing"
    review_reason = "接口未返回 review 结构，不得视为零风险"
elif review.get("status") in ("skipped", "not_run", "error"):
    review_state = str(review.get("status"))
    review_reason = str(review.get("reason") or "")
    review_error = str(review.get("error") or "")
issues = (review or {}).get("issues") if isinstance((review or {}).get("issues"), list) else []
```

3. 把"无 issue 文案"分支改为：
```python
if issue_lines:
    issues_text = "\n\n".join(issue_lines) + ("\n\n> 当前共发现 ..." if len(issues) > 10 else "")
elif review_state == "executed":
    issues_text = "未发现审查问题或警告。"
else:
    issues_text = f"审查未执行/异常（{review_state}）：{review_reason} {review_error}".strip()
```

4. 在最终 return 字典中增加：
```python
"review_state": review_state,
"review_reason": review_reason,
"review_error": review_error,
```

5. 保存。

### 2.4 节点「全流程交付报告格式化」（1786031004832）

1. 「输入变量」新增：

3. 「代码」页：
- 函数签名增加：
```python

review_state: str = "",
```
- 在 `number()` 转换区增加：
```python

```
- 把 pending_count 改为：
```python
pending_count = confirm_count + conflict_count + unknown_count \
                + environment_pending_count + manual_package_count
```
- 把终态 if 链改为：
```python
machine_error = (
    str(fiber_status) in ("失败", "FAILED", "解析失败")
    or str(construction_status) in ("失败", "FAILED", "解析失败")
    or review_state in ("error", "missing")
)
if machine_error:
    overall_status = "BLOCKED"
elif failed_rules > 0:
    overall_status = "CONDITIONAL_PASS_ESTIMATED"
elif pending_count > 0:
    overall_status = "CONDITIONAL_PASS"
else:
    overall_status = "PASS"
```
- return 中新增：
```python
"result_type": "formal" if overall_status == "PASS" else "estimated_or_conditional",
"stage_results_json": json.dumps({
    "review": review_state,
    "bom_success": bom_success if "bom_success" in dir() else None,
    "fiber_status": fiber_status,
    "construction_status": construction_status,
    "pending_count": pending_count,

```
